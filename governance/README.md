# Governance Library

This directory is the root governance library for Nunn Corporation and related governed platform ecosystems.

## Canonical Foundation

The first canonical document in this library is:

- `constitution/NUNN_CORPORATION_CONSTITUTION.md`

The first SentinelOS platform doctrine draft is:

- `sentinel-platform/SENTINELOS_EXECUTIVE_CONSTITUTION.md`

This constitution is the highest governing document for Nunn Corporation. Subordinate governance documents should identify their authority, purpose, status, owner, and position within the hierarchy before being treated as canonical.

## Corporate Governance Hierarchy

1. Constitution
2. Corporate Charter
3. Executive Governance
4. Board Governance
5. Management Operating Book (MOB)
6. Enterprise Manuals
7. Corporate Policies
8. Standards
9. Procedures
10. Operational Registers

## Governance Rule

No platform, operating, policy, standards, procedure, or register document should be promoted as canonical if it conflicts with a higher authority document.
