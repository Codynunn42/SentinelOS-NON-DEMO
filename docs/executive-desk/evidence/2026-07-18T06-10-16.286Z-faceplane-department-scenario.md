Excluded scope:
- hosted Sentinel AI remote execution
- distributed multi-node execution

Metric definitions:
- Docking latency: Elapsed local process time to build manifest, docking manifest, docking event, and SDK evaluation for one faceplane.
- Mission latency: Elapsed local process time for one synthetic faceplane mission batch including command generation, synthetic approvals, and synthetic blocks.
- Throughput: Total synthetic commands divided by total local process runtime for the department load loop.
