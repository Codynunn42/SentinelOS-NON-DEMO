# GBP Deployment Profile — State

## Profile Name

State

## Purpose

Support governed deployments for state-level organizations and shared service environments.

## Inheritance

- Inherits from MOB
- Inherits from GBP
- Uses the common Outcome Engine catalog
- Uses the common governance and evidence model

## Profile Characteristics

- Cross-agency coordination
- Shared service compatibility
- Moderate-to-high governance rigor
- Flexible integration model
- Strong reporting visibility

## Required Outcome Engines

- Governance Engine
- Evidence Engine
- Executive Operations Engine
- Mission Operations Engine
- Compliance Engine
- Integration Engine
- Identity Engine
- Workflow Engine

## Common Mission Packages

- Government AI Adoption
- Mission Readiness & Governance Operations
- Shared Services Governance
- Cross-Agency Evidence Operations

## Policy Overlays

- Approval routing by department or agency
- Shared governance policy catalog
- Delegation tracking across organizational boundaries
- Evidence retention aligned to state requirements

## Required Integrations

- Identity provider / SSO
- ITSM platform
- Records management archive
- Monitoring and observability stack
- Department-level reporting systems

## Evidence Requirements

- Receipts
- Approval chain logs
- Policy decisions
- Workflow traces
- Reporting snapshots

## MRI Profile Settings

- Governance: 25
- Risk: 20
- Evidence: 20
- Operations: 15
- Security: 10
- Financial: 10

## Readiness Criteria

- State identity model validated
- Shared reporting configured
- Evidence archive enabled
- Governance controls mapped
- Mission packages selected
