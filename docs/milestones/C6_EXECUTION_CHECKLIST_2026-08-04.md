# C6 Execution Checklist

## Sovereign Runtime — Institutional Onboarding Milestone

This checklist defines the required steps to onboard an institution into SentinelOS following Phase 2 evidence completion.

### C6.1 — Institutional Module Registration

- [ ] Load institutional module definitions for Finance, Operations, Compliance, and Communications
- [ ] Map institutional capabilities to sovereign modules
- [ ] Validate module-governance boundaries using module-governance-denial evidence
- [ ] Confirm module-resolution evidence emits for all institutional capabilities
- [ ] Confirm module-health evidence emits for institutional modules

### C6.2 — Institutional Identity Integration

- [ ] Enable institutional identity provider through the Sentinel Passport Authority
- [ ] Issue institutional passports for the initial cohort
- [ ] Bind identity to governed session to evidence chain
- [ ] Validate identity-linked evidence in SPE, SER, SEL, and SNCS
- [ ] Confirm the executive plane shows identity-linked evidence status

### C6.3 — Institutional Workflow Routing

- [ ] Configure institutional routing rules for provider selection and module boundaries
- [ ] Validate SNCS evidence for institutional workflows
- [ ] Validate module evidence for institutional workflows
- [ ] Validate AI routing evidence for institutional workflows
- [ ] Confirm the executive plane shows institutional routing evidence

### C6.4 — Institutional Executive Desk

- [ ] Enable institutional module view
- [ ] Surface institutional evidence status
- [ ] Validate evidence completeness for institutional capabilities
- [ ] Confirm module evidence appears for institutional modules
- [ ] Confirm AI routing evidence appears for institutional AI capabilities

### C6.5 — ORV-3 Institutional Readiness Suite

- [ ] Run ORV-3 module-resolution tests
- [ ] Run ORV-3 module-health tests
- [ ] Run ORV-3 governance-denial tests
- [ ] Run ORV-3 SNCS completeness tests
- [ ] Run ORV-3 AI routing tests
- [ ] Run ORV-3 executive-plane consistency tests
- [ ] Achieve ORV-3 score of 90 percent or higher

### C6.6 — Institutional Launch Readiness

- [ ] Generate institutional outcome briefing
- [ ] Complete executive sign-off
- [ ] Authorize institutional launch
