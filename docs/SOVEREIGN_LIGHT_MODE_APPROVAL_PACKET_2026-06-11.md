## Candidate Code Decision

The candidate replaces sovereign-license HMAC verification with Ed25519:

- Nunn Cloud retains the private signing key.
- A buyer receives only the public verification key.
- The public key verifies licenses but cannot sign or forge them.
- HMAC sovereign licenses are rejected as unsupported.
- No real keypair or buyer license is generated by this packet.
