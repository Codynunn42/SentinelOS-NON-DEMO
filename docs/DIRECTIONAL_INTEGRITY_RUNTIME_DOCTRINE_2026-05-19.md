## Drift Pressure

Drift Pressure predicts instability before failure.

```json
{
  "driftPressure": {
    "strategic": 0.04,
    "operational": 0.11,
    "trust": 0.02
  }
}
```

Drift pressure classes:

| Drift Pressure | Meaning |
| --- | --- |
| Strategic | deviation from North Star or strategic outcome |
| Operational | mismatch between intended workflow and observed state |
| Trust | degradation in identity, environment, runtime, audit, or evidence confidence |
| Governance | policy, approval, lifecycle, or inheritance misalignment |
| Public Trust | external claim, publication, or pilot exposure instability |

Drift pressure may recommend a hold, review, or escalation. It does not authorize remediation.

## Outcome Stability State

Outcome stability tracks persistence, not just completion.

```json
{
  "outcomeState": {
    "stability": "STABLE",
    "variance": 0.06,
    "confidence": 0.95
  }
}
```

Outcome stability states:

| State | Meaning |
| --- | --- |
| Unknown | insufficient evidence |
| Stabilizing | trend appears coherent but not yet persistent |
| Stable | outcome is consistent with evidence and trust state |
| Variance | outcome is not failing but is moving outside expected bounds |
| Drift | outcome deviates from governance, trust, runtime, or strategic expectations |
| Held | outcome cannot progress without authority decision |
