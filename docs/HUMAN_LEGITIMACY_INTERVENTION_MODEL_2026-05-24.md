## Why Humans Remain Essential

Humans preserve legitimacy when a system approaches transitions that could change authority, risk, audience, or operational consequence.

## Legitimacy Transition Points

| Transition | Human Role |
| --- | --- |
| review -> execution | approve or hold |
| proof -> publication | approve audience and claim boundary |
| metric -> decision | interpret evidence before authority |
| repository visibility -> settings mutation | approve exact scope |
| demo -> buyer-facing claim | confirm language and freshness |
| readiness -> deployment | confirm operational risk acceptance |

## Trust Restoration Path

If legitimacy is unclear:

1. Pause movement.
2. Preserve current state.
3. Reconcile evidence.
4. Identify authority gap.
5. Ask for operator decision.
6. Resume only within approved scope.
