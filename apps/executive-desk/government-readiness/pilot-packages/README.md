# Pilot Packages

Store pilot-ready packages for government stakeholders.

Each pilot package should include:

- mission context,
- decision objectives,
- scope and constraints,
- measurable outcomes,
- evidence and reporting plan.

## Required Delivery Standard

- Zero-dependency portability for offline or in-perimeter execution.
- A dual-front-door structure with an executive path and an operator path.
- A localized interactive control plane that demonstrates intent validation and governance state changes.
- A verification ledger or signed activity trail that proves user intent and preserves tamper-evident evidence.
- Executable overlay scaffolds such as JSON schemas, gateway policies, or configuration templates for day-one testing.

## Packaging Goal

The package should function as a secure, self-contained environment rather than a slide deck with recommendations.

Use [SOVEREIGN_PILOT_PACKAGE_STANDARD.md](SOVEREIGN_PILOT_PACKAGE_STANDARD.md) as the baseline for every government-ready package.
