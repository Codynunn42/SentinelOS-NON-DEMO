# Hotel Executive AI Pilot - Statement of Work and Success Criteria (v1)

Date: 2026-07-21  
Owner: Nunn Corporation  
Pilot Type: Connectivity-first executive AI pilot

## 1. Purpose

This pilot validates a secure executive AI integration pattern for hotel operations leadership.

Primary objective:

- Prove trusted end-to-end connectivity between Custom GPT and hotel-facing APIs through Microsoft Entra OAuth.

This pilot does not authorize operational command execution.

## 2. Architecture in Scope

ChatGPT or Custom GPT  
-> GPT Actions (OpenAPI)  
-> Microsoft Entra OAuth  
-> NunnCorp Integration Gateway  
-> Hotel and enterprise read endpoints  
-> Structured JSON response

## 3. Pilot Phases

### Phase 1: Connectivity Mode (in scope now)

Goal:

- Verify integration trust path and authenticated response flow.

### Phase 2: Executive Read Interface (conditional)

Goal:

- Add read-only executive insight endpoints once Phase 1 is accepted.

### Phase 3: Operational Mode (out of current scope)

Goal:

- Enable controlled write actions only after formal readiness gates pass.

## 4. Phase 1 Endpoint Contract

Initial safe endpoints:

- GET /health
- GET /ready
- GET /version
- GET /whoami
- GET /status

Initial OAuth scopes:

- profile
- hotel.executive.read
- hotel.system.status

No write scopes are required for Phase 1.

## 5. Success Criteria (Phase 1)

The pilot is successful when all five checks pass:

1. GPT imports the OpenAPI schema successfully.
2. OAuth sign-in completes through Microsoft Entra.
3. GPT obtains an access token.
4. GPT calls at least one protected endpoint successfully.
5. API returns valid structured JSON to GPT.

## 6. Explicit Out of Scope (Phase 1)

- POST /command
- POST /scan that triggers mutating workflows
- Any state-changing business action
- OTP-driven approvals for write operations
- Production operational automation

## 7. Security and Governance Baseline

Phase 1 baseline controls:

- OAuth bearer token required on protected endpoints.
- Scope-based authorization enforced for protected routes.
- Request logging with correlation IDs.
- Redaction rules for sensitive payload fields.
- No secrets, tokens, OTP values, private keys, or auth codes in support channels.

## 8. Phase 2 Entry Criteria

Phase 2 can begin only when:

- Phase 1 success criteria are met and signed off.
- Reliability checks for endpoint uptime and response consistency are met.
- Read-only executive insight payload contract is approved.

## 9. Phase 3 Entry Criteria

Operational mode can begin only when:

- Health and readiness gates pass.
- Authentication and authorization controls are validated.
- OTP or step-up controls are validated where required.
- Receipt and audit verification pipeline is validated.
- Rollback and incident procedures are documented and tested.
- Executive governance approval is recorded.

## 10. Deliverables

NunnCorp deliverables for this pilot stage:

- Phase 1 OpenAPI contract for safe connectivity endpoints.
- Entra OAuth integration configuration and validation checklist.
- Test evidence packet with request and response traces (redacted).
- Phase 1 evidence runbook for execution consistency and sign-off.
- Phase gate decision note: Phase 1 accepted or remediations required.

## 11. Roles and Responsibilities

NunnCorp:

- Build and configure integration gateway and OAuth integration pattern.
- Deliver endpoint contract, validation flow, and evidence artifacts.
- Provide remediation support for auth and connectivity failures.

Hotel pilot team:

- Provide tenant and app registration details.
- Register callback URIs exactly as generated by GPT Builder.
- Provide access to test environment and sample read data sources.
- Review and approve phase gate evidence.

## 12. Commercial Framing

Phase 1 is a capability validation milestone.

Post-pilot expansion model:

- Implementation fee for additional integrations and enablement.
- Platform subscription for managed updates, monitoring, and support.
- Professional services for custom workflows, analytics, and governance enhancements.

## 13. Approval

Pilot acceptance authority:

- NunnCorp executive owner
- Hotel pilot sponsor
- Security or compliance reviewer

Decision:

- Approved for Phase 1 closeout
- Remediation required before closeout
