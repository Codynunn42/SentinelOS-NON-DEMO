# Government Readiness Library

This library holds the core executive artifacts for federal engagement readiness.

## Structure

- DOE
- executive-intelligence
- deployment-profiles
- modernization
- governance
- executive-briefings
- pilot-packages
- mission-outcomes
- evidence

## Operating Rule

Every document in this library should map to a measurable mission outcome.

## Usage

1. Build executive-level materials first.
2. Keep language concise and outcome-first.
3. Avoid product-first framing.
4. Record evidence for every claim that informs a government decision.
