## Operating Rule

Every document in this library should map to a measurable mission outcome.

## Sovereign Delivery Standard

- Government-facing packages must be portable, local-first, and runnable without external cloud dependencies.
- Demonstrations must preserve human authority, evidence capture, and zero-trust control boundaries.
- Executive and operator audiences must each have a tailored entry path into the same package.

## Usage

1. Build executive-level materials first.
2. Keep language concise and outcome-first.
3. Avoid product-first framing.
4. Record evidence for every claim that informs a government decision.
5. Package pilot materials so they can execute securely inside a customer perimeter.
6. Use BOARD_INDEX.md as the board-facing entry point for Phase 6 review.
