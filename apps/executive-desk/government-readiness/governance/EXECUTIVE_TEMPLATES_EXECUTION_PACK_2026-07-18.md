## 3) DOE SBIR/STTR Readiness Gate

**Status:** **PRE-APPLICATION READINESS / ACTIVE ALIGNMENT**

DOE currently requires three registrations before an SBIR/STTR application can
be submitted: SAM, the SBA Company Registry, and the DOE SBIR/STTR Application
Hub. SAM can take substantially longer than the other two, while the SBA
Company Registry and Application Hub are comparatively quick once prerequisites
are available.

| Readiness Item | Status | Gate |
| --- | --- | --- |
| SAM registration | **SUBMITTED** | **WAIT** for IRS/TIN and CAGE validation, then confirm Active |
| SBA Company Registry | **NOT YET CONFIRMED** | **ACTION REQUIRED** once ready |
| DOE SBIR/STTR Application Hub | **NOT YET CONFIRMED** | **ACTION REQUIRED** |
| U.S. for-profit small-business eligibility | **LIKELY ALIGNED / VERIFY FORMALLY** | Confirm against SBA program criteria |
| Topic alignment | **STRONGEST: AI-DRIVEN AUTONOMOUS LABORATORIES** | Continue fit analysis |
| Phase I technical concept | **NEEDS FORMALIZATION** | Define one bounded feasibility objective |
| Milestones / Go-No-Go criteria | **NEEDS FORMALIZATION** | Build measurable Phase I gates |
| Commercialization pathway | **PARTIALLY READY** | Tie to pilots, licensing/SaaS, and federal use case |
| National lab / research partner | **RELATIONSHIP LANE EXISTS** | Do not claim partnership unless formal |
| IP / data rights posture | **NEEDS APPLICATION-SPECIFIC REVIEW** | Preserve proprietary rights appropriately |
| Security-risk due diligence | **OPEN READINESS ITEM** | Prepare ownership, affiliations, foreign ties, and key-personnel disclosures as required |
| Letters of support | **NOT YET ASSEMBLED** | Collect only from real supporters or partners |

### Technical Fit

The strongest current DOE topic fit is **Achieving AI-Driven Autonomous
Laboratories**, which describes integrating AI directly into experimental
workflows, including real-time analysis, intelligent feedback, hypothesis
generation, robotics or edge AI, and data curation or sharing.

> A governed AI execution and evidence layer for scientific workflows that adds
> explicit authority boundaries, human approval, provenance, reproducibility,
> and auditable decision trails.

This should be framed as an enabling layer for scientific AI workflows, not as a
claim that Nunn Cloud already operates autonomous laboratories.

### Program Fit

DOE's SBIR/STTR structure is commercialization-oriented. Applicants enter
through Phase I feasibility work and advance through later phases based on
milestone and Go/No-Go performance. DOE Phase I applicants begin with a pitch,
and a full application follows only after invitation. Registrations and support
materials should be completed early.

### Current Opportunity Posture

The July Genesis Phase I release included four topics and anticipated about 40
awards. DOE also stated that a broader Phase I opportunity would follow later
in fall 2026.

**Gate posture:** Do not force-fit into the current Genesis topic if the
technical fit is weak. Prepare the registrations, capability statement,
feasibility concept, and commercialization evidence so Nunn Cloud can move
quickly when the broader Phase I release opens.

### Executive Gate Decision

**ADVANCE**

- Complete remaining DOE and SBA registrations.
- Formalize one Phase I governed-AI feasibility concept.
- Define measurable milestones.
- Prepare commercialization evidence.
- Prepare security and due-diligence disclosures.
- Monitor the broader Phase I release.

**HOLD**

- Unsupported autonomous-lab claims.
- Claims of DOE or national-lab partnership without formal evidence.
- Production-readiness claims.
- Speculative hardware or GPU commitments.
- Broad multi-topic proposals.

### Gate-Exit Criteria

Nunn Cloud is **SBIR/STTR application-ready** when all of these are true:

**SAM Active -> SBA Registry complete -> DOE Application Hub complete ->
specific topic selected -> bounded technical hypothesis -> measurable Phase I
milestones -> budget -> commercialization plan -> team roles -> IP/data-rights
position -> security-risk disclosures -> support letters where applicable.**

At that point, the Executive Template status can move from:

> **PRE-APPLICATION READINESS**
>
> to **APPLICATION-READY / TOPIC-SPECIFIC REVIEW**
